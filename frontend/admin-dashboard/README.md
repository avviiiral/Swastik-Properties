# Legacy Admin Dashboard Workspace

**This standalone workspace is no longer the active frontend.**

Public and Admin experiences have been combined into one Angular SSR application under `frontend/public-website`. Run that single application to access both areas:

- Public website: http://localhost:4200/
- Admin sign-in: http://localhost:4200/admin/login
- Admin property management: http://localhost:4200/admin/properties

Use the setup instructions in [the unified frontend README](../public-website/README.md). Do not start this legacy workspace separately. It is retained temporarily for reference while the unified application is reviewed.
